# Starship Commission Date

A lightweight Stellaris mod that records and displays the commission date for newly built ships.

## Features
- Captures commission date on ship creation
- Displays in Ship Inspector and hover tooltips
- Format: Commissioned: May 12, 2214
- Vanilla compatible

## Installation
Copy the `starship-commission-date` folder to `Documents/Paradox Interactive/Stellaris/mod/`

## Compatibility
Stellaris 4.x (all versions)
